# 本次制作说明

## 制作过程

1. 使用由 GPT 生成的智乃正面插画，通过 See-Through 生成分层 PSD。
2. 检查自动拆层：帽子主体被放入 `topwear`，将其分离为 `headwear_1`，让帽子跟随头部。
3. 调整播放器对 `-l`、`-r` 图层命名的识别，并添加 `legwear` 的身体分组。
4. 完整模型保留 1280 × 1280 画布、22 个图层；默认模型裁为 800 × 800 半身构图。
5. 将默认 PSD、闭眼与闭嘴差分内嵌到 `形象数据.js`，基本展示无需额外下载。
6. 将默认界面设为中文，添加“导出8秒动态预览”按钮，整理离线入口与分享说明。

## 文件与验证

默认模型自动绑定为 25 个部件、12 束头发；验证了 PSD 解码、面部锚点、内嵌差分与脚本语法，并在本地播放器展示中检查了眨眼、单眼眨眼和头部角度调整。

`index.html` 与 `打开形象.html` 内容相同，前者作为标准网页入口，后者便于离线双击打开。

## 效果限制

- 完整画布的鞋部自动拆层不完整，默认半身版避开这一区域。
- 嘴部差分为简化效果，没有制作精细的逐音素口型。
- 摄像头与麦克风追踪没有做实际设备验证；直接 file:// 打开不支持这些功能。
- 这是 2.5D 网页形象，不是 Cubism 模型导出包。
