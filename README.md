# 智乃动态形象 · 离线分享版

把一张由 **GPT 生成的智乃插画** 做成可以在浏览器中展示的 **2.5D 动态形象**，支持自动眨眼、发丝摆动、表情切换和头部参数调节。

分享整理：[奶龙大人sama](https://space.bilibili.com/12723119) · [B站主页](https://space.bilibili.com/12723119)

![智乃效果预览](智乃_效果预览.png)

## 快速开始

1. 下载并解压完整项目文件夹。
2. 用 Edge 或 Chrome 打开 **`index.html`**，也可以打开 **`打开形象.html`**。
3. 等待模型加载，点击“普通”“微笑”“左眼眨”等按钮，或调节头部、眼睛、嘴巴的参数。

无需安装 Python、ComfyUI 或额外模型。默认模型及闭眼、闭嘴差分已内嵌到 `形象数据.js`，基本展示可离线运行。请保留 `lib/` 和 `形象数据.js`，不要只复制 HTML。

只想看效果，可以直接播放 [智乃_动态预览.mp4](智乃_动态预览.mp4)。

## 能展示什么

- 自动眨眼、待机动作与头发物理。
- 普通、微笑、半闭眼、惊讶、左右单眼眨眼等表情预设。
- 手动调节头部角度、视线、眼睛开度和嘴部参数。
- 透明、绿幕和暗色背景，以及 8 秒动态预览导出。
- 拖入其他符合命名规则的分层 PSD，尝试自动绑定。

默认使用 **800 × 800 半身模型**。这是网页运行的 2.5D 效果，口型采用简化差分；本包不包含 Cubism 的 `.moc3` 或 `.model3.json`。

## 常见问题

**打开后空白或模型未出现？**

先确认已完整解压，`形象数据.js` 与 HTML 位于同一目录，`lib/` 中的文件完整。使用支持 WebGL 的现代浏览器；基础展示不需要登录账号。

**为什么默认只展示半身？**

自动拆层的完整画布在鞋部有缺失，因此默认使用半身构图。完整 PSD 也保留在 `可编辑模型/` 中，方便继续修正。

**能用摄像头或麦克风吗？**

分享版主要用于形象播放与表情演示。直接以 `file://` 打开时不支持摄像头、麦克风追踪。这些入口需要 localhost 或 HTTPS，以及浏览器权限；摄像头功能还会加载外部 MediaPipe 文件。本次没有验证实际摄像头和麦克风追踪效果。

**是否可以作为静态网站入口？**

项目提供 `index.html`，静态服务器可以从目录首页加载。所有基础展示资源使用相对路径，无构建步骤；部署时保留原目录结构。
